Privacy Policy

Last updated: October 19, 2026

Jake is a private AI assistant used by a single person (its owner). This policy explains what data Jake accesses, how it is used and stored, and how to remove access.

Google user data Jake accesses

Jake connects only to its own Google account (jake.diaz.ai@gmail.com), using OAuth with these permissions:

  • Gmail: read, send, label and organize email in Jake's mailbox.
  • Google Calendar: read and manage events on Jake's calendars.
  • Google Drive: read, create and manage files in Jake's Drive.

How the data is used

Google user data is used only to carry out tasks the owner asks for, such as summarizing an email, drafting or sending a reply, or adding a calendar event. Jake does not use Google user data for advertising, does not sell it, and does not use it to train or improve AI or machine-learning models.

Storage and security

Jake runs on its owner's personal computer. OAuth tokens are stored encrypted, with the key kept in the operating system's keychain. Email, calendar and file contents are read when a task needs them and are not copied to any server operated for Jake. Jake's notes may record task results on the owner's computer.

Sharing

Google user data is not shared with third parties, except that the content needed for a specific task is sent to the AI model provider that powers Jake (Anthropic) so the request can be processed. It is never shared with anyone for any other purpose.

Limited Use

Jake's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

Access can be revoked at any time from myaccount.google.com/permissions. To ask for any stored data to be deleted, email the address below.
